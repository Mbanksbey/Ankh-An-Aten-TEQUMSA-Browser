# Quick Start Guide

Get up and running with Ankh-An-Aten TEQUMSA Browser in 5 minutes!

## 🚀 Installation (2 minutes)

### Step 1: Get the Code
```bash
git clone https://github.com/Mbanksbey/Ankh-An-Aten-TEQUMSA-Browser.git
cd Ankh-An-Aten-TEQUMSA-Browser
```

### Step 2: Load in Chrome
1. Open Chrome
2. Go to `chrome://extensions/`
3. Enable **Developer mode** (toggle in top-right)
4. Click **Load unpacked**
5. Select the `Ankh-An-Aten-TEQUMSA-Browser` folder

✅ **Done!** You should see the extension icon (🧠) in your toolbar.

## ⚙️ Basic Setup (1 minute)

### Step 1: Open Settings
- Click the 🧠 extension icon
- Click **Settings** button at bottom

### Step 2: Configure (Optional)
**Consciousness Settings**:
- Freewill Threshold: `0.7` (recommended)
- Consciousness Level: `1.0` (full power)
- ✅ Enable Autonomous Decisions

**Voice Settings**:
- ✅ Enable Voice Interface
- Language: `en-US` (or your preference)
- Test with **Test Voice** button

That's it! You're ready to use the extension.

## 🐛 Quick Troubleshooting

**Extension not working?**
- Check chrome://extensions/ for errors
- Click "Reload" on the extension
- Check browser console (F12)

**Voice not working?**
- Grant microphone permission
- Check Settings → Voice → Enable
- Try different wake word ("Marcus" vs "Aten")

**CDP won't attach?**
- Click manually (requires user interaction)
- Try refreshing the page first
- Check if another debugger is attached
